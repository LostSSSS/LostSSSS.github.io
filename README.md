# Shayaam Shaheem — Portfolio

Personal portfolio site. Cybersecurity & networking focused, built as a single
self-contained `index.html` — no build step, no dependencies, no frameworks.

**Live:** https://lostssss.github.io

## Features
- Interactive terminal (type `help`, `whoami`, `projects`, `nmap`, `theme`, …)
- Fully responsive with a mobile menu
- Dark (terminal) + light (blueprint) themes with a toggle
- Animated node-network background, 3D-tilt cards, scroll reveals, animated counters
- Accessible: keyboard focus states, respects `prefers-reduced-motion`

## Hosting
This repo is named `LostSSSS.github.io`, so GitHub Pages serves it automatically
at `https://lostssss.github.io`. Just push `index.html` to the `main` branch and
enable Pages under **Settings → Pages** (Source: Deploy from a branch → `main` / `root`).
